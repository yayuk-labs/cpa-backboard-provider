Backboard

Connect Backboard to CPA. Add one key at a time; each key gets its own credential.

Authorizes saving keys and model settings to CPA. Kept only while this page is open.

API keys

The key is validated with Backboard before it is saved.

Use a unique prefix to keep tool conversations on this key. Example: work/backboard/openai/gpt-4o-mini

Models and aliases

Choose the models available to all Backboard keys. Enter exact provider and model names; the full catalog is never needed for a selected list.

An empty selected list disables all models. Full catalog discovery loads thousands of models.

Alias is optional. For example, alias backboard-mini lets you request that name. Without an alias, use backboard/provider/model-name. Credential routing prefixes still apply.
